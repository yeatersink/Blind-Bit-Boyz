9.7 Native dependency risk

package.json trustedDependencies includes esbuild, keccak, and secp256k1.

esbuild is the Vite transformer. It is present at node_modules\esbuild. A missing platform binary for esbuild would stop vite dev. The binary was not executed for this report.

keccak and secp256k1 are not direct dependencies. package-lock.json shows them under ethereum-cryptography version 0.1.3, which is a dependency of ethereumjs-util. That package sits in the Moralis and EVM utility tree. Locked versions present in node_modules: keccak 3.0.4 and secp256k1 4.0.5.

Both packages declare an install script "node-gyp-build || exit 0" and "gypfile": true. The "|| exit 0" means a failed native compile does not fail npm install by itself. node_modules already contains prebuilds for keccak (darwin-x64, linux-x64, win32-x64) and secp256k1 (darwin-arm64, linux-x64, win32-x64). Neither package has a build directory in this checkout. On this Windows x64 tree, a matching prebuild file is present, so a from-source compile is not required for those two packages to load here. Other CPU or libc targets are not all covered by the prebuild folders that were listed. This report did not import the native modules.

Bun uses trustedDependencies to decide whether those install scripts may run. npm runs install scripts unless ignore-scripts is set. .npmrc does not set ignore-scripts.
